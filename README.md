## 📖 Sobre o Projeto

O app é uma aplicação móvel desenvolvida para o setor médico com o objetivo central de revolucionar e otimizar a comunicação entre profissionais de saúde, clínicas e pacientes. 

A solução atua como uma ponte digital para mitigar falhas de comunicação, garantindo que atualizações críticas de agenda como a ausência imprevista de um médico sejam repassadas aos pacientes de forma imediata e automatizada.

## 🎯 O Problema e a Solução

**O Problema:** Historicamente, a falta de uma comunicação eficiente no agendamento médico gera uma cadeia de impactos negativos. Pacientes frequentemente enfrentam deslocamentos desnecessários e perda de tempo devido a cancelamentos de última hora não informados, o que resulta em alta insatisfação e sobrecarga no atendimento das clínicas.

**A Solução:** Nossa plataforma resolve esse gargalo comunicacional automatizando o fluxo de avisos. Ao melhorar a eficiência operacional das clínicas, o aplicativo eleva significativamente a experiência do usuário final (o paciente), garantindo previsibilidade e respeito ao seu tempo.

## ✨ Funcionalidades Principais

* **🩺 Registro de Ausência em Tempo Real:** Interface dedicada para que médicos ou administradores de clínicas registrem ausências (imprevistos, atrasos ou emergências) de forma instantânea.
* **📲 Notificações Automatizadas (Push/SMS/Email):** Disparo automático de alertas via dispositivos móveis para todos os pacientes impactados por cancelamentos de consultas ou exames.
* **🔄 Sincronização de Agenda:** Atualização em tempo real do status da clínica para os usuários conectados.
* **👥 Portais Dedicados:** Visões específicas e seguras baseadas no perfil de usuário (Paciente, Médico e Administração da Clínica).

## 🛠 Tecnologias Utilizadas 

* **Frontend (Mobile):** React Native 
* **Backend:** Node.js
* **Banco de Dados:** SQLite 
* **Mensageria/Notificações:** WhatsApp API
